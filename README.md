# Astronaut Vitals — NASA Space Apps Challenge 2026

Папка проекта: prompt для AI-инструмента, чек-лист подачи и план работы.

## Файлы
- `PROMPT.md` — готовый промпт для AI-инструмента (код приложения создаётся по нему).
- `SUBMISSION_CHECKLIST.md` — что заполнить и проверить на странице Project Submission.
- `README.md` — этот файл, план и список приложений.

## Что нужно (приложения и сервисы)

| Что | Зачем |
|---|---|
| **VS Code** или **Cursor** | редактирование кода |
| **Claude Code** (или Cursor / Lovable) | генерация приложения по `PROMPT.md` |
| **Node.js LTS** | запуск сборки, если выберете React + Vite |
| **Git + GitHub** | хранение кода и публикация |
| **GitHub Pages / Netlify / Vercel** | публичная ссылка на приложение без логина |
| **Google Slides** или **Canva** | 7 слайдов демо |
| **QuickTime (Mac) / OBS** | запись видео демо ≤ 30 сек |
| **Google Drive / YouTube** | публичная ссылка на демо (проверьте в приватном окне) |
| **Figma** (необязательно) | макет интерфейса |
| **Chrome** | тестирование и проверка ссылок |

## План работы (до 23:59 15 ноября)
1. **Сейчас:** создать команду на сайте, открыть вкладку Project, сохранить название и краткое описание.
2. **Сборка:** отправить `PROMPT.md` в AI-инструмент, проверить структуру, запустить локально, исправить ошибки.
3. **Деплой:** выложить на GitHub Pages / Netlify, проверить ссылку в приватном окне.
4. **Демо:** записать видео ≤ 30 сек или сделать 7 слайдов, выложить на Google Drive / YouTube.
5. **Страница проекта:** заполнить все поля по чек-листу, включая раздел SI и NASA Data.
6. **Отправка:** Save Progress → галочки → Submit for Judging. Не откладывать на последнюю минуту.
7. **Сертификат:** скачать после отправки (PDF, Letter).

- Укажите в описании, какие AI-инструменты использовали (SI).
