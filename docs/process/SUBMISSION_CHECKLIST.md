# Чек-лист подачи проекта — NASA Space Apps Challenge 2026

**Дедлайн: воскресенье, 15 ноября 2026, 23:59 по местному времени вашего Local Event.**
Подача открывается в субботу 14 ноября в 9:00. Нужно нажать **«Submit for Judging»** до дедлайна, иначе проект не будет оценён, а сертификат не выдадут.

## 1. Команда
- [ ] Все участники — подтверждённые участники одного Local Event.
- [ ] Владелец команды видит вкладку **Project** в разделе **My Team** (появляется с 14 ноября, 9:00).

## 2. Страница проекта (все поля на английском)
- [ ] **Project Name** — например: «Astronaut Vitals».
- [ ] **High-Level Project Summary** — что сделали, как решает задачу челленджа, почему это важно.
- [ ] **Link to Project Demo** — публичная ссылка на видео (до 30 сек) или на слайды (до 7 слайдов). Без пароля и регистрации.
- [ ] **Link to Final Project** — публичная ссылка на работающее приложение (GitHub Pages / Netlify / Vercel). Без логина.
- [ ] **Detailed Project Description** — что делает, как работает, какие пользы, какие инструменты и языки использовали.
- [ ] **NASA Data** — конкретно: какие данные/ресурсы NASA использовали (обязательно минимум один, иначе нет права на Global Award). Например: страницы NASA HRP Hazards и Risks.
- [ ] **Space Agency Partner Data and Other References** — все использованные данные, код, тексты, картинки, включая открытые. Укажите CSA (Canadian Space Agency) — ссылки из задания.

## 3. Раздел «Use of Super Intelligence (SI)»
- [ ] Ответить «Yes» и описать, где использовали AI (код, тексты, картинки).
- [ ] На AI-картинках и видео — **видимый водяной знак** «AI-generated».
- [ ] В коде и данных — **текст и метаданные** с пометкой, что это сгенерировано AI (например, комментарий в шапке файла и строка в README).
- [ ] Не используйте логотипы, флаги или символы миссий NASA в дизайне.
- [ ] AI не должен придумывать идею решения — идея должна быть вашей.

## 4. Демо
- [ ] Формат: видео ≤ 30 секунд **или** слайды ≤ 7 (включая титульный).
- [ ] На слайдах/в видео: название команды, имена участников, выбранный челлендж, проблема, как работает, пользовательский опыт, как используются данные NASA, видение на будущее.
- [ ] Хостинг: YouTube / Google Drive / GitHub / Dropbox — ссылка открывается в приватном окне.
- [ ] Язык: английский (для видео допустимы субтитры на английском).
- [ ] Если в демо есть люди младше 18 лет — их нельзя показывать.

## 5. Файлы и картинки
- [ ] Картинки на странице проекта: JPG, PNG или GIF, до 10 МБ.
- [ ] Видео и документы загружать на страницу нельзя — только ссылки.
- [ ] Ссылки проверить в приватном окне браузера.

## 6. Финальная отправка
- [ ] Поставить галочку **«Terms and Conditions»**.
- [ ] Поставить галочку **«Confirm All Work is Original»**.
- [ ] Нажать **«Save Progress»** заранее, потом **«Submit for Judging»**.
- [ ] Дождаться баннера с подтверждением вверху экрана.
- [ ] Можно переотправлять до конца хакатона — оценят только последнюю сохранённую версию.

## 7. Сертификат
- [ ] После отправки: Profile → Participant Information → «2026 NASA Space Apps Challenge» → «Download Participant Certificate» (формат Letter, PDF).
- [ ] Имя в Profile → Full Name должно быть указано полностью (имя и фамилия).
